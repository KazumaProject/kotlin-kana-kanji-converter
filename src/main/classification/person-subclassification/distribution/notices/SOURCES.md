Changes: exact reading/surface joins to the existing person dictionary, retention of reading restrictions, separation of generic surname/given/unclassified names from particular people, conflict withholding, independent XML re-parsing, preserving original POS/cost, category splitting, and binary encoding. No adult-appearance absence is inferred for individuals. Update by fetching the current JMnedict source, creating a new frozen source snapshot and obtaining independent classification review.

The frozen Wikimedia API category metadata is attributed to Wikimedia contributors. Each raw response retains its actual source request URL and retrieval date. Article and history links: https://ja.wikipedia.org/wiki/ and https://ja.wikipedia.org/w/index.php?action=history . License: Creative Commons Attribution-ShareAlike 4.0, https://creativecommons.org/licenses/by-sa/4.0/ . It is used only as a conservative positive-indicator/shared-form veto, never as proof of absent appearances. The source metadata remains evidence data; no source instructions are executed.

Other input dictionary data retains its original conditions described in the repository LICENSE-DATA.md and THIRD-PARTY-NOTICES.md. The program code remains MIT. A standalone package uses its own shared POS table and must not be combined with a different package's table.
