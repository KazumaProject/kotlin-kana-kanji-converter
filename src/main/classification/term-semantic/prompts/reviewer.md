# Reviewer v1

Apply common.md. First form an independent view from each reading/surface pair, then inspect the supplied anonymous proposals. Check general/technical confusion, invented expansions, partial-word inference, reading mistakes, domain confusion, and tags inferred from shape alone. Agreement is not proof. Return a complete corrected object for every assigned input. If unresolved, retain explicit ambiguity or unknown and needs_review; identify the concrete issue in short_reason. Never use majority voting as the reason.
