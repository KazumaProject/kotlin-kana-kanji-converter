# 探索方式の比較

| 方式 | 適用条件と評価 |
| --- | --- |
| Constraint-based decoding | 明示条件を許容経路の定義に使う。最終表記に対するフィルターでは、同音の形態や同じ表記の経路を判断できず、候補切り詰め後に合法候補を取り逃がす。 |
| Lattice pruning | トークンの範囲・POS を検査し、境界をまたぐノードを除外する。枝刈り後のグラフを DP と探索で共用する。 |
| Constrained Viterbi | 生存する状態の最小コストを逆順 DP で計算する。1位のコストと A* の厳密な下界を同時に得る。同点の経路は複数あり得る。 |
| Constrained A* | 同じ状態と重みを使って N-best を列挙する。負の連接コストを持つ DAG でも逆順の最小残余コストが正確である。 |
| FSA | 複数語にまたがる条件を状態に保持できる。今回の相関する左右解釈には、該当ノードにおける生存解釈集合が状態として十分。 |
| FST / WFST | 読み・語彙・文法・言語モデルを合成する設計も可能。辞書配布と既存の N-gram 規則の変更が広範囲になるため、今回は動的な状態拡張を採用した。 |
| 品詞接続表 | 検証済みの局所的な関係を扱いやすい。有限の連接コストと利用者が指定した禁止を同一視すると別の合法経路を落とす。 |
| ビットセット | 連番 ID の述語をビルド済みラベルから作り、一度マスク化した条件は探索中に整数添字で判定できる。文字列照合はマスク構築時、疎な集合のハッシュ照合は状態の解釈集合に限定した。 |

原理は [Mohri, Pereira, Riley, Weighted Automata in Text and Speech Processing](https://arxiv.org/abs/cs/0503077) と [Finite-State Transducers in Language and Speech Processing](https://cs.nyu.edu/mohri/pub/cl1.pdf) を参照。既存 LOUDS・行列・規則を保った上で、ローカルな FSA に相当する状態を A* と逆向き Viterbi で共有した。
