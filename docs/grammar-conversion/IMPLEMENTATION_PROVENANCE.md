# 独自実装の由来

調査チェックアウトは worktree の外で管理した。メジロ式の調査では入力・出力・文法情報が実装されている位置を特定し、機能の有無を記録した。設計・コードは、このリポジトリのラティスと辞書データ、一般文法、仕様付きの固定入力・探索アルゴリズムに基づく。

| 実装 | 根拠・流用範囲 |
| --- | --- |
| `GrammarMetadata`・`GrammarConstraint` | プロジェクトの `MozcIdDefParser`、連番 ID、UTF-16 ノード境界。既存の辞書由来ラベルを判定に用いる。 |
| `GrammarSearch`・`GrammarConversion` | 本リポジトリの既存 GraphBuilder、N-best 優先規則、加法コスト付き DAG の最短経路と A*。相関する解釈の状態と全表記到達性を独自実装した。 |
| `Inflection`・`GrammarConnections` | [一般文法資料](JAPANESE_GRAMMAR.md)、当該辞書の品詞、入力・出力仕様に基づく独自の規則とテスト。 |
| コーパスとテスト | ユーザー指定語、このプロジェクトの回帰ケース、自作のひらがな短文と固定 seed の生成ラティス。 |
| CLI と計測 | 既存の資産ロードと Kotlin JSON、JVM 標準のタイマー・スレッド割り当て・GC 管理 API。 |

メジロ式のコード、ストローク割当、辞書、活用・助詞テーブル、テストデータ、ライブラリやバイナリは、実装とビルド入力に含まれていない。既存の辞書資産やライセンスファイルは編集していない。
