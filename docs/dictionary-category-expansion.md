# カテゴリ追加と、未分類をさらに救済する方針

今回の読み確認済み・未分類16,360件について、固定DBの型とJMdict語義の分野を集計しました。**以下の型件数は対応候補の集計であり、そのまま採用できる件数ではありません。** 同名検索・曖昧さ回避・読みと対象の対応は採用前に再確認します。

## 新カテゴリの有力候補

まず `organism`（動植物・菌類などの生物名。個体名も含む場合は定義を明記）を検討します。現在の12分類では、競走馬を人名へ、実在の生物を架空キャラクターへ分類するのは適切ではありません。

| 保存済み型の候補 | 読み確認済み未分類での対応件数 | 例 |
|---|---:|---|
| 分類群 Q16521 | 1,031 | キングサリ、リーガルリリー、アオサナエ |
| 化石分類群 Q23038290 | 458 | アイシェアイア、アウストラロティタン |
| ウマ Q726 | 580 | アイアムアクトレス、アスクワンタイム |

動物・植物をさらに別辞書にする場合、分類群という型だけでは区別できません。属・科等の分類階級と生物学的な上位分類（Wikidata P171等）を固定データへ追加する必要があります。現在のP31/P279型の親だけで、全てを動物または植物に振り分けることはできません。菌類・微生物・化石も扱える定義を先に決めます。個体名と種名の独立した役割も保存します。

次候補はスポーツ・競技語と宗教・文化語です。JMdictで制約付きの読み・語義を確認できた未分類には、sumo85、MA44、sports28、baseb26、Buddh120、Shinto35、Christn15の対応があります。同じペアの複数分野は重なるため、合計を収録数にはしません。競技名・技・地位・大会を区別し、大会は既存event、チームはorganizationへ残します。宗教上の人物・神と、教義・儀礼・用具も区別します。

## 新カテゴリを増やさずに直す対象

- イタリアの基礎自治体Q747074：1,331件の型対応候補。地名の具体型・祖先到達の不足を調べ、placeへ救済する対象。
- テレビ番組Q15416：595件。対象と読みが確かならworkに収録する対象。
- 特定の化学物質型Q113145171：382件。親型と具体的な意味を確認し、technicalの分類経路を補う対象。
- 姓Q101352、人Q5、駅Q55488にも未分類がある。型を増やすだけでなく、別名・本名・同名対象の対応不足を先に解決する。

曖昧さ回避Q4167410にも402件の型対応候補があります。この数を一般語や新カテゴリへ流し込みません。独立した語義を確認できるJMdict・公式資料へ照合します。

## 追加する際の受入条件

1. 既存5入力にある語だけを対象とし、カテゴリ定義・型・語義・除外例を固定する。
2. 読みを確認したまとまった有用語があることを確認する。生物名は500件以上、狭い分野を別辞書にする場合は100件以上を初期の検討目安とし、件数を得るための推測はしない。
3. 現在の600語・200文を保持したまま、新カテゴリ50語と文章ケースを別の追加評価セットへ固定する。既存評価を入れ替えて後退を隠さない。
4. 新規採用100件（未満なら全件）の読みと対象・分類の根拠を点検し、保留も調べる。
5. CLIの選択、カテゴリmanifest、共有POS、ZIP、ライセンス、Actionsの件数・評価・レビューゲートを更新し、Linux再現性を確認する。
6. 辞書名だけで用途を理解できる配布文書、実測の例・未収録例・移動数を保存する。

現在の公開判定は検証済み12カテゴリ版に対して行っています。カテゴリ追加の数値は調査候補の数であり、標準収録372,438件に含めていません。

## 再集計

```sh
python3 scripts/report-dictionary-category-gaps.py \
  --snapshot build/dictionary-metadata/snapshot.sqlite \
  --audit build/reports/dictionary-quality/audit.tsv.gz \
  --output build/reports/dictionary-quality/category-gaps.json
```

JSONには全分野の件数と例、上位50型の対応件数を残します。名前の型・読みを同じ対象へ結び付ける検証を追加してから、採用見込み件数を確定します。
