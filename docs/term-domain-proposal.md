## 固定データと根拠

- [分類定義](../src/main/classification/term-domain-proposal/taxonomy.json)
- [分類結果（gzip圧縮TSV）](../src/main/classification/term-domain-proposal/assignments.tsv.gz)
- [件数・ハッシュ・手順・出典](../src/main/classification/term-domain-proposal/manifest.json)

分類TSVはヘッダー付きUTF-8です。列は `reading`・`surface`・`category`・`confidence`・`tags`・`method`・`evidence`・`reference_ids`。タグとJMdictの項目IDはカンマ区切りです。

JMdictの分野タグ・語義から作った学習ラベルでローカルの文字n-gram分類器を学習し、読みと表記の特徴、分野を示す語幹・接尾辞、抜き取り時の意味判断で補正しました。分類注釈を固定しており、検証・書き出し時にモデル推論や外部通信は行いません。

確信度「高」はJMdictの単一分野タグとの対応、「中」は語形・語義等からの推定、「低」はモデル推定、複数分野、根拠間の不一致等です。正答確率として校正した値ではありません。独立資料による読み確認や専門家による全件確認とは区別します。

曖昧な語や複数語義のある語も主カテゴリを1つに仮分類しています。一般語の頻度・実用性は評価していません。追加タグが付かないことは、その性質がないことの証明ではありません。

## ローカル検証と辞書ソースの書き出し

```sh
python3 scripts/term_domain_proposal.py verify
python3 scripts/term_domain_proposal.py report --check
python3 -m unittest discover -s scripts -p test_term_domain_proposal.py -v
python3 scripts/term_domain_proposal.py export --output build/term-domain-proposal
```

Python標準ライブラリのみで実行できます。出力先は未作成のディレクトリを指定します。主カテゴリ26種類とタグ5種類の6列TSVを生成し、元の品詞・コストを含む全レコードを読み戻して照合します。既存の本番カテゴリ定義・固定判断・配布バイナリは更新しません。

固定分類の再集計・照合・辞書ソース生成が再現対象です。分類器の再学習は対象外で、モデル、JMdictキャッシュ、ローカル環境、個人の絶対パスは含めていません。後続の修正では語単位の分類根拠を見直し、分類ファイル・件数・ハッシュ・本書を合わせて更新します。

## 配布への切り替え

この案を本番へ採用する場合は、既存の分類判断と衝突を解決したうえで、カテゴリ定義・追加語の分類方法・固定配布データ・カタログ・利用側IMEの読み込み先を更新する必要があります。追加タグは同じ語を重複収録するため、利用側での読み込み・重複排除方針も決めます。IME用バイナリの生成、実アプリの表示・順位・互換性は、この提案では検証していません。
